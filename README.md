# SpriteForge — редактор спрайтов в стиле Aseprite с синхронизацией в Unity

Сайт: **https://sunakle.github.io/isepute/**

## Запуск
1. Дважды кликните `start.bat` (нужен Python 3). Запустится локальный сервер и откроется сайт.
   Сайт на GitHub Pages сам не может писать файлы на диск — это делает сервер на `127.0.0.1:7777`.
   Без сервера на сайте можно рисовать и скачивать PNG. Если браузер спросит про доступ к локальной сети — разрешите.
   Тот же редактор доступен и офлайн: http://127.0.0.1:7777
2. Скопируйте папку `unity/Assets/Editor/SpriteForge` в `Assets/Editor/` своего Unity-проекта.
3. В Unity: **Window → SpriteForge**. Плагин сам сообщит сайту путь к проекту (индикатор станет зелёным).

## Структура
- `docs/` — сайт (GitHub Pages публикует эту папку)
- `server.py`, `start.bat` — локальный сервер синхронизации (только стандартная библиотека Python)
- `unity/Assets/Editor/SpriteForge` — плагин для Unity Editor

## Как работает синхронизация
- Сайт сохраняет спрайт (Ctrl+S или автоматически, если включён **Live**):
  - `Assets/Sprites/SpriteForge/<имя>.png` — sprite sheet (кадры в одну горизонтальную полосу)
  - `<проект>/SpriteForge/<имя>.sforge.json` — исходник со слоями и кадрами (как .aseprite)
  - `<проект>/SpriteForge/<имя>.info.json` — размеры кадров, длительности, pivot, PPU
- Плагин Unity раз в секунду опрашивает сервер и делает `AssetDatabase.Refresh()`.
- Импортёр ставит pixel-art настройки (Point filter, без сжатия, PPU, pivot) и режет полосу на кадры `<имя>_0`, `<имя>_1`…
- Для анимаций (2+ кадра) создаётся `<имя>.anim` с длительностями кадров — перетащите на объект со SpriteRenderer.
- «Открыть» на сайте показывает все PNG из папки Unity, даже нарисованные в другой программе.

## Графический планшет (XP-Pen и др.)
- Перо рисует сразу. В строке состояния внизу видно «перо, нажим N%» — значит, планшет распознан.
- **Нажим → размер**: сила нажатия меняет толщину до значения «Кисть».
- Обратный конец пера — ластик (если у пера он есть), кнопка на пере — фоновый цвет (как ПКМ).
- **Без касаний**: палец и ладонь на сенсорном экране не рисуют.
- Если нажим всегда 50% или 100%: в драйвере XP-Pen (Pentablet) включите **Windows Ink**.

## Экспорт проекта
«Экспорт проекта» скачивает проект целиком (слои, кадры, длительности, палитра):
- `.sforge` — формат SpriteForge, открывается кнопкой «Открыть файл».
- `.aseprite` — открывается в Aseprite. «Открыть файл» умеет загружать и `.aseprite`/`.ase` из Aseprite.

## Горячие клавиши (как в Aseprite)
| Клавиша | Действие |
|---|---|
| B / E / I / G | карандаш / ластик / пипетка / заливка |
| L / U / Shift+U | линия / прямоугольник / эллипс |
| M / V / H, пробел | выделение / перемещение / рука |
| ПКМ | рисовать фоновым цветом; Alt+клик — пипетка |
| X | поменять цвета местами |
| Shift при фигурах | квадрат / круг / линия под 45° |
| [ ] | размер кисти |
| , . / Enter | кадр назад / вперёд / проиграть |
| Alt+N / Alt+B / Alt+C | новый кадр / пустой кадр / удалить кадр |
| Shift+N | новый слой |
| Ctrl+Z / Ctrl+Y | отмена / повтор |
| Ctrl+A / Ctrl+D / Del | выделить всё / снять / очистить |
| Ctrl+C / Ctrl+X / Ctrl+V | копировать / вырезать / вставить |
| колесо, + / − / 0 | масштаб / вписать |
| Ctrl+S | сохранить в Unity |
